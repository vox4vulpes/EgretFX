# Changelog

Each release's notes on GitHub start with its section from this file — the
release workflow refuses to publish a version that has no section here.

## [1.1.1]

### Changed
- **Egret EQ 1.1.1**: lighter on the CPU (15–20% less load; AUTO GAIN 4–6
  times quicker on the audio thread), with exactly the same sound.

## [1.1.0]

### Changed
- **Egret EQ 1.1.0**: dynamic EQ per band, EQ Sketch, Character (Clean,
  Subtle, Warm), a movable and see-through band panel, a list of all the
  bands, and an update check when the plugin starts (Help turns it off).
- The Linux builds link libcurl for the update check.

## [1.0.0]

### Added
- The Egret FX bundle, with its first effect: **Egret EQ 1.0.0**, a
  parametric EQ with up to 48 bands (ten shapes, 6–96 dB/oct, stereo, left,
  right, mid or side), analog-matched curves, a pre/post analyzer, solo, auto
  gain, presets, undo/redo and A/B.
